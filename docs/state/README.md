# State notes

One file per change, `YYYY-MM-DD-topic.md`, with the section it would have added to `docs/STATE.md`
(`## Title — branch \`name\`` and its lines). Read these together with `docs/STATE.md` when resuming: they are the newest
state. `npm run notes` (pos folder) appends them to `docs/STATE.md` before a release. Why: see `changes/README.md`.
