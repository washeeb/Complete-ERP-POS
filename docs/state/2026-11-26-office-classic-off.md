## New back office, part 43: the classic back office switched off (branch `office-classic-off`, base `office-addresses`)
- **Switch:** `config('erp.classic_back_office')` (env `ERP_CLASSIC_BACK_OFFICE`, default false). `App\Http\Middleware\ClassicOff` is the first middleware of the Filament panel: with the switch off, a GET/HEAD to `/admin…` redirects to `OfficeUrl::from(...)` (query kept, `tableSearch` → `q`); other methods pass (Livewire posts of a page left open fail on their own). `/` redirects to `/office/`. `phpunit.xml` sets it true, so the tests of the dormant classic pages still run.
- **Kept dormant, not deleted:** the Filament resources and pages (the new screens reuse their queries, permissions and forms), `EnforceLicense`, `RedirectToSetupWizard`, the `IndustrySwitcher` Livewire component, `UserPrefs::homeUrl`. Deleting them is a later clean-up, page by page.
- **New look:** `NotificationsController` + `shell/Bell.tsx`; `shell/IndustrySwitch.tsx` + `POST office-api/industry` + `me.industry`; `me.licence` + the licence redirect in `OfficeController::index` and App (licence first, then setup). Removed: `me.classic`, every `classic=` prop, PageHead/ProcList/ReferenceListPage `classic`, the classic item of the user menu and of My profile, `ClassicPage` (now `GoToNew`: `/office/a/…` navigates to `appPathFor`).
- **Scripts:** `check:layout` (`scripts/layout-check.mjs`) now checks the new look (2 looks × 2 sizes × 5 pages: sideways scroll, squashed list, menu reach, menu panels inside the window). `manual:screens` signs in at `/office/sign-in` and finds each picture's page through `office-routes.json`; new `sign-in.png` (old `admin-login.png` removed). `office-check` checks that old addresses open the new page and that nothing opens in a frame.
- **`erp:page-timings`:** GET `office-api/*` routes without parameters (files, exports and search-only calls skipped), each in its own savepoint (one failing query aborted the shared PostgreSQL transaction before); `--deep` opens `rows[0].id` of a list when a record route exists; `--errors`.
- **Tests:** `OfficeClassicOffTest` (4: redirects, bell, licence gate, industry switch).
