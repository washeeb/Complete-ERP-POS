## Till new look, part 1: theme, tiles and the selling screen (branch `till-new-look-1`, base `main`)
- **Owner decisions (2026-11-28):** tiles + cart by default, with a setting for the old layout in the new look; tiles free; the company colour on Pay and each window's main button; order: 1 shell + selling, 2 payment and receipt, 3 drawer / shifts / cash-up, 4 returns and approvals, 5 sign-in, settings and the industry screens. **Next (part 1b):** choose each branch's favourite tiles in the back office.
- **Theme:** `src/ui/TillTheme.tsx` wraps the app (main.tsx) in Fluent's `FluentProvider` with `themes()` from `office/src/theme.ts` (one source for brand contrast), light/dark from `<html data-theme>` or the device; `applyBrand()` sends the company colour (`ui/brandEvent.ts`). `App.css .till-root` maps the till's CSS variables (--bg, --panel, --text, --muted, --line, --primary, --accent) to Fluent tokens, so every screen follows; status colours stay the till's.
- **Catalog:** `GET pos/catalog` sends `categories` (the categories of the products sold there); `catalogVersion` includes the categories table. Till stores them in the cached catalog.
- **Selling screen:** `screens/ProductTiles.tsx` (category TabList + tile grid, up to 60 per category, accessible names "Name, price[, stock]"); shown while the search box is empty and `prefs.layout === 'tiles'` (prefs.ts, Till settings → Selling screen). Layout: `.sell` flex column, `.work` two-column grid filling the height (the old grid left the panels half-height); `.pay-btn`.
- **Tests:** a11y e2e catalog has categories; new tests for tiles and the list layout; axe excludes Fluent's Tabster focus sentinels (`[data-tabster-dummy]`). E2E clicks on quick-cash amounts are scoped to the Payment window and cart checks to the Cart (a tile can show the same text). `PosSaleTest`: categories in the catalog and a rename refreshes it.
- **Size:** Fluent adds ~51 KB gzip to the till (vendor 14 → 65 KB); precache 709 → 904 KB.
