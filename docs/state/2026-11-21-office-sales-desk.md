## New back office, part 16: the rest of Sales (branch `office-sales-rest`, base `office-sales-orders`)
- **Server:** `App\Domain\Office\SalesDeskScreen` (tillRequests with the push key, returns / returnDoc / returnForm, review, cards / cardHistory) and `Office\SalesDeskController` (push subscribe; return approve / cancel; `sales/{sale}/return` form and submit through `OfficeReturns::submit`; resolve through `ReviewQueue`; sell through `StoredValues::sellCard`). Approving a till request still goes through `OfficeController::decideTillRequest`. `SalesScreen` gives the sale page `actions.return`.
- **Push keys:** `PhonePush::newKeys()` makes the VAPID pair with `resources/openssl/openssl.cnf`; `installer/windows/install.ps1` sets `OPENSSL_CONF` (machine and `php-worker.cmd`) so the library's per-message key works on Windows. Dev on Windows: start PHP with `OPENSSL_CONF` set to that file to send notifications locally.
- **Client:** `TillRequestsPage` (polls every 5 s; `home/push.ts` registers `/push-sw.js`), `OfficeReturnsPage`, `OfficeReturnPage`, `ReturnGoods` (on `SalePage`), `ReviewQueuePage`, `GiftCardsPage`. Paths `/admin/till-requests(?id=)`, `/admin/office-returns(/{id})`, `/admin/review-items`, `/admin/stored-values` → `/office/till-requests`, `/office/office-returns…`, `/office/review-queue`, `/office/gift-cards`.
- **Tests:** `OfficeSalesDeskTest` (4, including the notification key). office-check opens the four from Sales.
