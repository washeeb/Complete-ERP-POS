## System pages in the new back office (first half)
- **System is rebuilt in two parts**: about 2,000 lines of current pages; this half is what is opened most (health, backups, licence, audit, problem reports, integrations); Go-live, Import data, API clients, Mobile money, Support access and Sync Center follow.
- **Backup destination secrets never leave the server**: their boxes come back empty and an empty box keeps the saved one, as the current form; every save is tested with a copy first.
- **The installation code and its QR only reach the owner or general manager**; everyone else still sees the licence state, so they know why the system is locked.
- **Back up now and Check the newest backup answer when done** (they may take minutes), as the current buttons.
