# Decision notes

One file per change, `YYYY-MM-DD-topic.md`, with the section it would have added to `docs/DECISIONS.md`
(`## Title (date)` and its points: what was found, what was decided, and why). They are the newest decisions.
`npm run notes` (pos folder) appends them to `docs/DECISIONS.md` before a release. Why: see `changes/README.md`.
