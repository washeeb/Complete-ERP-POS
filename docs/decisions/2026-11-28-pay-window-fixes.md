## Till windows keep their buttons in view
- **One height for the payment window:** switching the way to pay no longer moves the buttons under the cashier's hand; what is due never scrolls away.
- **Fixed in the shared window style, not window by window:** every till window scrolls inside itself with its bottom buttons kept in view, so a new window gets it too. The 11 windows sharing the payment window's class keep their own layout.
- **A test holds it:** every way to pay and the daily windows at three screen sizes, buttons on screen and not covered.
- **Last seen = any contact:** a health report is contact from the till; showing it as older than the health report confused the owner.
