## Devices and computers in the new back office
- **The enrolment code is shown once,** in a dialog after Register or New code, and is not in the list afterwards (a test checks it). Losing it means giving a new code, as now.
- **Remote support stays a link** to the relay (View screen, Take control), opened in a new tab; the relay route checks and audits again, as now.
- **Send a fix keeps its rule:** only with the Remote access add-on and the control level at that branch (DeviceHealth); the server refuses otherwise.
- **Actions sit in a menu on each row,** since a device can have up to eight of them.
- **What it did** still opens the audit log filtered to that computer; the audit log is not rebuilt yet, so it opens the current page inside the new back office.
