## Installer carries on when only PHP's package source is mid-update
- **Found (probed with curl):** packages.sury.org republishes about hourly (05:16, 06:21 GMT on 2026-11-21); its network keeps `InRelease` up to an hour (`max-age=3600`, ignores `no-cache`) but serves the new `Packages.xz` sooner, so apt sees a size mismatch for up to an hour after each publish. The repository has no by-hash files, so apt cannot avoid it. Retrying for two minutes is not enough.
- **Decided:** on an update, a failed PHP index is not a reason to stop when PHP is already installed: the server keeps its PHP and gets PHP's updates next time. Only when every error is about packages.sury.org; any other source failing still stops, and a first install (no PHP yet) still stops with "wait a few minutes".
